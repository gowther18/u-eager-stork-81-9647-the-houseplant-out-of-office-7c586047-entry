The Houseplant Out-of-Office — one out-of-office auto-reply, at most 120 characters, as if a houseplant had written it: the fern on the desk, unwatered since March, blackmailing its human with the browser history it has seen. This program writes that one line to /output/entry.txt; a judge model compares the lines two at a time, and the funniest line takes the prize.

## Run it

```sh
python3 main.py
```
